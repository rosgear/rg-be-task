## <img src="https://raw.githubusercontent.com/rosgear/rg-be-task/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Модуль «Системные задачи»

Модуль входит в состав Панели управления GePanel.

Функционал модуля обеспечивает управление системными задачами в рамках Панели управления GePanel: создание, настройку расписания, отслеживание статуса выполнения и анализ результатов.

### Установка

Для добавления модуля в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-task
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-task": "*"
}
```
или скачать архив на [странице модуля](https://rosgear.ru/component/rg-be-task/) в каталоге приложений RosGear.

После добавления модуля в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

<a name="english"></a>
## <img src="https://raw.githubusercontent.com/rosgear/rg-be-task/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Module «System tasks»

The module is part of the GePanel Control Panel.

The module's functionality enables management of system tasks within the GePanel Control Panel: creation, scheduling, tracking execution status, and analysis of results.

### Installation

To add the module to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-task
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-task": "*"
}
```
or download the archive from the [module page](https://rosgear.ru/component/rg-be-task/) in the RosGear application catalog.

After adding the module to the project, install it into the web application edition using the GePanel Control Panel.
